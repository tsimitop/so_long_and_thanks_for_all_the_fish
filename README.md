The so_long project is the first project that includes graphics in the 42 core curriculum.

The goal of the project is to make a mini game with a character that moves on a 2D plane, collects collectibles and exits when it is finished.

My character for now is a snail that collects mushrooms and exits from a bush. I wanted to play around with simply applying colors to
the tiles depending and their position and status but haven't gotten round to it yet.


TO PLAY THE GAME:

Clone the repo (obviously).
Make.
Run by typing ./so_long [map_you_want_to_play]

You can create your own maps if you like. Error messages will help you navigate the requirements to make your map valid.
Have fun! :snail:
